# v0.4 architecture examples

These files specify v0.4 formats. The package source remains version 0.3.0 while
the collection, directory, workspace, shard, and Studio-service infrastructure
has completed local TFSB46A qualification. The expanded brand runtime remains
future phased work after TFSB47A. Digest values in architecture examples are
schema-shaped illustrations, not receipts for external content.

Source-map examples use the canonical schema-1 key order. A deployed map is
named `.tfsb-source-map.toml` at its source root; the descriptive filenames in
this directory let the examples coexist.

The [brand-system tree](brand-system/README.md) contains the selected seven
producer domain files, consumer lock, compiled brand manifest, QA/diff/export
receipts, and Studio DTO projection. It copies no Terminal Nova production SVG
or legal bytes.
