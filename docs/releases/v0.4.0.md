# Theme Forge Stellar Burst v0.4.0

Theme Forge Stellar Burst v0.4.0 is the core release in the coordinated
Theme Forge family release with Nebular Fusion v0.1.0. The products have
separate public histories, versions, artifacts, release records, and rollback
identities.

## Highlights

- Collection-aware directory snapshots, source maps, bounded shards, typed
  directory provenance, and read-only workspace aggregation extend the
  project lifecycle.
- Opt-in brand systems provide families, roles, variants, typed tokens,
  deterministic recipes, legal/package metadata, consumer profiles and locks,
  semantic brand diffs, and renderer-bound visual QA.
- The optional `resvg-png-v1` adapter provides the closed PNG export surface
  when its exact pinned companion and renderer tuple is present and qualified.
  SVG remains canonical, and ICO/ICNS are not release claims.
- The `tfsb.studio` protocol adds typed brand and visual-evidence methods through v1.2 while retaining
  backward-compatible protocol v1.0 negotiation. Nebular Fusion remains an
  independently locked application.

## Installation

After the public npm publication is read back, install the core package with:

```sh
npm install --global @knowledge-forge-ai/theme-forge-stellar-burst@0.4.0
```

Node.js `22.0.0` or later is required. The final registry tarball, integrity,
dist-tags, packed consumer smoke, and CLI/native checks are authoritative only
when recorded from the published registry response and downloaded bytes.

## Optional raster companion

The raster companion is intentionally private and remains
`@knowledge-forge-ai/tfsb-raster-resvg@0.0.0-tfsb47f`. It binds
`@resvg/resvg-wasm@2.6.2` and is not a separately published npm product. The
paired Nebular distribution consumes the exact authenticated archive and lock
input rather than an inaccessible registry dependency.

The archive is `knowledge-forge-ai-tfsb-raster-resvg-0.0.0-tfsb47f.tgz`.
Use the final release checksum file and the paired
`authenticated-inputs/stellar-binding.json` to verify the archive, companion
package metadata and lock before installation. These identities are generated
from the qualified release inputs.

The companion release
payload carries `LICENSE`, `NOTICE`, `COMMERCIAL-LICENSE.md`, `MPL-2.0.txt`,
and `THIRD_PARTY_NOTICES.md`.
