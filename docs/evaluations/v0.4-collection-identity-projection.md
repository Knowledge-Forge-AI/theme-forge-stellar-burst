# v0.4 collection and identity projection

## Status and authority

This is read-only architecture evidence for v0.4 source-map, collection,
workspace, and shard decisions. It is not import permission, legal review, or a
redistribution claim. The machine record is
[`v0.4-collection-identity-projection.json`](v0.4-collection-identity-projection.json),
SHA-256
`aa16199927751d7c115ee2682e603093d40f0f79841e6d02e743c7eff7360b84`.

The projection helper validates each public origin, requires a clean worktree,
binds exact HEAD, walks proposed collection roots without following links,
runs the productized v0.3 analyzer, computes both proposed identity algorithms,
and freezes representative 16/32/128 sorted membership lists. Two independent
runs were byte-identical.

```sh
npm run build
node tools/project-v0.4-collection-identities.mjs \
  --simple-icons "$DOGFOOD_ROOT/simple-icons" \
  --lucide "$DOGFOOD_ROOT/lucide" \
  --tabler-icons "$DOGFOOD_ROOT/tabler-icons" \
  --thesvg "$DOGFOOD_ROOT/thesvg" \
  --output projection.json
```

The committed JSON contains no local absolute path or SVG/source content.

Tabler has 1,054 shared basename groups affecting exactly 2,108 files across
outline and filled. `outline-` and `filled-` reduce cross-collection collisions
to zero. Prefixes solve identity ambiguity; they do not authorize a 6,184-asset
transaction. Full representation would require 41 outline and 9 filled child
projects at the 128 ceiling.

When scoping to the `public/icons/` collection root (12,446 regular SVGs),
theSVG has 15 basename collision groups affecting 12,439 files (compared to 17
groups / 12,444 files when scanning the entire repository in v0.3). Seven files
in `public/icons/` have unique basenames. Scoped collection roots change the
collision picture without whole-repository noise. Closed relative-path derivation
within this collection has zero collisions, but 36 IDs exceed the new
source-map-local 64-byte maximum, with maximum 81 bytes. Those paths require
short explicit overrides. The algorithm never truncates or adds numeric/hash
suffixes.

All proposed roots have zero portable/case-collision findings and no symlink or
special-file entries. Repository-wide tracked-entry evidence remains distinct:
Simple Icons has tracked symlink `.nvmrc`, so full-root directory traversal must
still reject it. Selecting `icons/` demonstrates collection-root value without
weakening full-tree safety.

## Disposition

The evidence supports basename identity for Simple Icons, Lucide, and each
Tabler style; disjoint prefixes for Tabler; and relative-path identity plus
explicit overflow overrides for theSVG. It supports a separate workspace of
bounded children and does not support raising mutation limits, adding SVG
features, treating full collections as importable, or making legal claims.
