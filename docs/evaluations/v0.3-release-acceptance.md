# v0.3 release acceptance matrix

## Disposition

The implemented v0.3 surface is qualified as a release candidate for TFSB35
qualification. This document establishes package version `0.3.0` in a
release-candidate state and does not claim that v0.3.0 has been released or
published. Every qualified row below is backed by executed tests or generated
dogfood evidence; documentation or static inspection alone never supplies a
pass.

The resulting-state gate passed TypeScript checking, 37 Vitest files / 534
tests, 117 Playwright tests including local-only shard raster evidence, zero
production vulnerabilities, a 103-entry package dry run, and `git diff
--check`. Two independent dogfood qualification runs were byte-identical.

## Permanent TFSB33 recovery regressions

The seven required behaviors remain executable:

1. `reconcile2.test.ts` honors explicit archive/canonical resolution when a
   changed source normalizes to the prior model.
2. `normalized-import.test.ts` binds ledger evidence to actual raw and
   canonical digests, including semantic-equal formatting normalization.
3. `normalized-import.test.ts` refuses to discard authored title/description.
4. `reconcile2.test.ts` handles a deleted companion under canonical resolution.
5. `reconcile2.test.ts` handles a deleted asset under canonical resolution.
6. `analyze-parity.test.ts` classifies noncanonical points and paint whitespace
   as normalization rather than direct import.
7. `migration.test.ts` refuses execution of a check-mode migration plan.

## User journeys and deterministic outputs

- Terminal Nova covers migration check/apply, byte preservation, stale receipt,
  format, build, install, check, list, diff, bundle, preview, and idempotency for
  absent, partial, and complete provenance.
- Direct canonical schema 2 covers import through manifest re-import and preview
  without normalization authority.
- Combined noncanonical input covers title-only, decorative, and
  consumer-labelled authority with currentColor, primitives, gradients,
  fallback paint, local xlink, transforms, groups, and whitespace. Dry-run and
  applied ledgers are equal.
- Changed normalized source covers source-only, canonical-only, conflict,
  format-only, missing/changed/equivalent authority, deletion, and explicit
  archive/canonical resolution.

Determinism is executable for canonical TOML/SVG, policy and map identity,
provenance, normalization ledgers, migration and analyzer JSON, bundle ZIP,
preview output, and machine envelopes. No intentionally nondeterministic field
is accepted in the retained machine artifacts.

## Deferrals

Schema 3, collection/source-map/workspace identity, directory mutation,
higher limits, unsafe repair, arbitrary CSS/XML, Studio/GUI work, package
versioning, publication, tags, and releases remain outside TFSB34.
