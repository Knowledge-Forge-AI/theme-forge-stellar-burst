## Browser evidence

`test/visual/dogfood-shards.spec.ts` compares source and canonical raster bytes
at natural viewBox size and 16, 24, 32, 64, 128, and 256 CSS pixels. Chromium
covers every selected lifecycle entry. Firefox and WebKit select deterministic
representatives for accessibility, presentation, geometry, transforms, and
outline/filled families. The focused run passed all three browser projects.

When local-only evidence is not configured, the browser test skips with an
explicit reason instead of treating absent checkouts as product failure.
